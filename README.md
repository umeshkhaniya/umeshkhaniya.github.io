## Selected Projects

### [Microstate Analysis of a Protein](https://github.com/umeshkhaniya/microstate_lysozyme_analysis)

This project focuses on identifying the correct protonation state for molecular dynamics simulations using microstates generated during Monte Carlo runs. It is used in the Marilyn Gunner Lab and includes functionality for free energy analysis and PDB writing.

- Tools: Python 3
- Input: Microstate file from MCCE output
- Output: Protonation state of the protein

### [Drug Discovery Using a Machine Learning Approach](https://github.com/umeshkhaniya/Drug-Discovery-using-the-Machine-Learning-approach)

This project explores machine learning methods for predicting the IC50 values of aromatase inhibitors.

- Tools: Streamlit, scikit-learn, Python 3
