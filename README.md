# Project

### [Project 1: Microstate Analysis of a Protein](https://github.com/umeshkhaniya/microstate_lysozyme_analysis)

This project invloves the novel way of finding the right protonated state for Molecular Dynamics Simulation. In this project, millions of microstates obtained during the Monte Carlo run are used for analysis. This is now used in  Marilyn Gunner Lab to find the protonation state and  also has free energy, PDb writing functionality. 

This project involves a novel method for identifying the correct protonation state for Molecular Dynamics simulations. It uses millions of microstates generated during a Monte Carlo run for analysis. This approach is currently used in the Marilyn Gunner Lab to determine protonation states and includes features such as free energy calculations and PDB writing functionality.

* **Python Libraries Used:** Python3
* **Input:** Microstate file from MCCE output
* **Output:** Protonation state of the protein
